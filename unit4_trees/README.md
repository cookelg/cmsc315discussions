3. *Explain BST behavior and compare to how ordering works to create efficiency as compared to other data structures.*
Each BST node has a minimum of three data members: the node's value, a left pointer 
to another node, and a right pointer to another node. The first node added to a BST is 
identified as the root of the tree. When the next node is added, if the new nodes value
is greater than the root node, its pointer is added to root.right; root.left if the value 
is less than root's value. All nodes are added to the tree in this manner; all nodes 
that have a value less than root are found on the left branch, and all values greater 
than are found on the right branch. This enables a value in the tree to be efficiently 
found, yielding O($log_{2}N$) efficiency.
