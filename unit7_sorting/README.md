This discussion enabled me to deep dive into how merge sort works and enabled me 
to experiment with different ways to implement it. The biggest challenge I encountered 
was the complexity of how merge sort works. The recursive calls to break down the list 
into individual segments was easy to make sense of. However it became a lot more 
difficult to wrap my head around merging them all back together. 

Bubble sort is the most basic of all the sorting algorithms, and its time efficiency
is the worst of the lot because it uses a nested for-loop to find the lowest value 
for that index before moving on, making it O(N^2). Merge sort is a much more time 
efficient sorting algorithms with a runtime efficiency of O(N * logN). Its drawbacks 
are that it is a complicated algorithm to implement.
